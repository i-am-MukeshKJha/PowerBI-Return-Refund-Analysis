# Power BI Return & Refund Analysis

## 📊 Project Overview

This project is a Power BI dashboard designed to analyze return and refund patterns.

The dashboard provides insights into:

- Total Orders
- Returned Orders
- Return Rate
- Refund Amount
- Return Reasons
- Product Categories
- Sales Channels
- Returned Units
- Average Return Days
- Discount vs Return Rate
- Product-level return performance

## 🎯 Business Objective

The objective of this project is to understand customer return behavior, identify major return reasons, analyze refund amounts, and discover product and sales-channel patterns.

## 📌 Key KPIs

- Total Orders: 1,767
- Returned Orders: 466
- Return Rate: 26.37%
- Refund Amount: 2.25M
- Returned Units: 674
- Average Return Days: 15.07

## 📈 Dashboard Analysis

### Return & Refund Trends

The dashboard analyzes refund amounts and returned orders across different months.

### Return Reasons

The major return reasons analyzed include:

- Product Not As Expected
- Damaged Product
- Wrong Size
- Quality Issue
- Wrong Item
- Defective Product
- Late Delivery
- Changed Mind

### Product Category Analysis

The dashboard compares returned units and total orders across categories such as:

- Fashion
- Electronics
- Home & Kitchen
- Beauty
- Books
- Sports

### Sales Channel Analysis

Returns are analyzed across:

- Mobile App
- Website
- Marketplace
- Offline Store

### Product Analysis

The dashboard provides product-level metrics including:

- Total Orders
- Returned Units
- Return Rate
- Refund Amount
- Average Discount
- Average Return Days
